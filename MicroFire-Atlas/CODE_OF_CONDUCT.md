# Code of Conduct

We want MicroFire Atlas to be a friendly place to learn and build, for students, researchers and young explorers alike.

- Be kind and patient. Assume good intent. Critique code and ideas, never people.
- No harassment, discrimination, or personal attacks of any kind.
- Welcome beginners. Explain, don't gatekeep.
- Honesty matters here: do not invent data, sources or results.

Maintainers may edit or remove comments, commits and issues that break these rules, and may ban repeat offenders. Report concerns by opening a private security/conduct report through the repository's GitHub "Report" option, or contact the maintainers listed on the repository page.

Adapted from the Contributor Covenant 2.1 (https://www.contributor-covenant.org).

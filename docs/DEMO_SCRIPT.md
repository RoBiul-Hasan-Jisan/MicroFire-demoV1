# 3-minute demo

**0:00 The problem (20 s).** NASA has decades of microgravity combustion data in PDFs. Mission planners need to know what it says, how sure it is, and what is missing. Open `/mission`.

**0:20 Honest evidence (35 s).** Pick a lunar cabin on `/mission`. The Evidence Ladder shows there is no direct NASA test at lunar gravity. Say it: "Our strongest feature is that it tells you what NASA has not tested."

**0:55 What the model can say (35 s).** `/predict` then `/limiting-oxygen`: the model's 50 % oxygen line over the real tests. Point at the honest score (accuracy about the same as guessing, Brier better) and at the pressure panel that says "cannot tell".

**1:30 Turning gaps into a plan (40 s).** `/next-tests`: "If NASA could run only 4 more tests, run these." Open the sensitivity table: the kind of test is robust, the exact order is not.

**2:10 Hypothesis, clearly labelled (25 s).** `/gravity-bridge`: move the sliders, show the "Unvalidated hypothesis" badge and the scorecard against NASA's own statement.

**2:35 Fires that go unnoticed (15 s).** `/unseen`: the "?" row, where nobody has data.

**2:50 Planner output (10 s).** `/brief`: a cited cabin brief downloaded as Markdown. Close: "Every number is traceable, every guess is labelled."

      How an answer is made

      Fixed rules read your question. The answer is then computed from NASA tables that our team transcribed or downloaded, and every row keeps its table, page and DOI. No AI writes a number, a finding or a verdict.

      AI agents can ask the same questions through this project’s MCP server. Its tools return the computed answer and its source rows, so an agent can quote the evidence but can’t invent it.

      Our team transcribed the test values. The oxygen values match NASA’s own PSI-25 table, and an independent check of the other columns is still pending. The chamber flame is an illustration, not footage.

      NASA reports and datasets

      • NASA/TM-20210011385, the BASS-II summary report: Table 5.1 acrylic sheets (p. 57), Table 7.1 SIBAL fabric (p. 96), Table A.2 Nomex (p. 105) and Table 2.1 extinction speeds (p. 28)
      • PSI-25 BASS-II, PSI-69 FLEX and PSI-99 Saffire-II, from NASA Physical Sciences Informatics (CC0)
      • NASA OCHMO-TB-008 Rev A, Fire Protection (2023), which lists the ISS fire-response steps
      • NASA evidence report (2015) on the 8.2 psi, 34% O₂ exploration atmosphere, which replaced 8.0 psi and 32% in 2012
      • Saffire VI results (ICES-2024-365) and Saffire IV and V (ICES-2021-266)
      • LUCI lunar-gravity burns (2025) and SoFIE
